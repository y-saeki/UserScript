# Kill Keyboard Shortcut on Github Notifications

- Github通知画面のキーボードショートカットを無効化します
    - 通知一覧はショートカットによる既読化・アーカイブなどの破壊的操作が多く、誤操作の影響が大きいためです

## 動作

- ページ読み込み時に、`data-hotkey` 属性を持つ全ての要素からその属性を削除します
    - Githubはこの属性でショートカットの対象要素と割り当てキーを表現しているため、削除するとショートカットが機能しなくなります

> [!NOTE]
> 属性の削除はスクリプト実行時の1回のみです。  
> その後にDOMへ追加された要素（client-side navigationや通知の追加読み込みによるもの）には適用されないため、確実に無効化したい場合はページをリロードしてください。

## 有効になる画面

- `https://github.com/notifications` 配下

## 設定

- 設定項目はありません
