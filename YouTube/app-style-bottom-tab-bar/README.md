# YouTube App Style Bottom Tab Bar

- YouTubeに、スマートフォンアプリ風のボトムタブバーを追加します
    - あなたがアプリでの閲覧に慣れている場合、PCブラウザでの閲覧時にアプリと体験を共通化できます

## 動作

- 画面下部に、以下4つのタブを固定表示します

| タブ | 遷移先 |
| --- | --- |
| Home | `/` |
| Shorts | `/shorts` |
| Subscriptions | `/feed/subscriptions` |
| Library | `/feed/library` |

- 現在のパスに対応するタブは、アイコンを塗りつぶし表示に切り替えます
    - `/shorts` 配下は、すべてShortsタブを現在地として扱います
- 動画再生画面（`/watch`）では、タブバーをフェードアウトさせて非表示にします
- `head` の子要素の変更を監視し、client-side navigationによる画面遷移にも追従します
- ブラウザの表示言語が日本語（`ja`）の場合、タブのラベルを日本語に差し替えます
- デスクトップ表示のミニサイドバーは、タブバーと役割が重複するため非表示にします

## 有効になる画面

- `www.youtube.com` 配下のすべてのページ
    - ライブチャット（`/live_chat`）を除く

## 設定

- 設定項目はありません
- 表示位置やサイズは、スクリプト内 `init()` の `<style>` で調整できます
